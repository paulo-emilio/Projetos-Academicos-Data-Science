## Detalhes do projeto

Projetos desenvolvidos com Python no Jupyter Notebook, utilizando bibliotecas como Seaborn, Matplotlib, SciPy, Pandas e scikit-learn, além de projetos em Excel, Google Sheets, Databricks e Power BI. Cobrem análise exploratória, modelagem estatística, machine learning e visualização de dados.

- 🏠 **Previsão de Preços de Imóveis** — modelo de regressão linear para estimar preços de imóveis a partir de um dataset real, com simulador interativo.
- 📊 **Perfil Socioeconômico Brasileiro (PNAD)** — análise estatística de dados da Pesquisa Nacional por Amostra de Domicílios.
- 🇧🇷 **Panorama Demográfico do Brasil (IBGE)** — análise descritiva de indicadores populacionais e socioeconômicos.
- 📈 **Dashboards e Planilhas Inteligentes** — soluções de BI em Power BI, Excel e Google Sheets para diferentes cenários de negócio.
- 🎓 **Pós-graduação em Ciência de Dados** — avaliações e estudos de caso desenvolvidos durante a pós-graduação.
